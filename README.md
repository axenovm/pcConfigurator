# ConfiguratorPC: Система анализа и оценки комплектующих

## Описание проекта
Конфигуратор — полнофункциональное **full-stack веб-приложение** для выбора, сохранения и анализа пользовательских сборок ПК. Система помогает пользователям конфигурировать сборки, **автоматически выявляет и исправляет недостатки**, анализирует производительность и совместимость.

---

## Основные функции системы
- **Выбор компонентов**  
- **Аутентификация**  
- **Рецензирование** (отзывы и рейтинг сборок)  
- **Аналитика активности** пользователей  

---

## Архитектура системы
- **Backend**: Spring Boot (REST API, валидация совместимости, расчёт TDP/производительности)  
- **Frontend**: React (интерактивный конфигуратор, дашборд, отзывы)  
- **База данных**: PostgreSQL (реляционная модель, индексы, JSONB для гибкого анализа)

---

## Ключевые возможности

### ER-модель базы данных (PostgreSQL)

## Ключевые возможности

| Функция                        | Описание | Таблицы / Поля |
|--------------------------------|----------|----------------|
| **Выбор компонентов**          | Интерактивный подбор процессора, материнской платы, ОЗУ, видеокарты, накопителей, БП, корпуса и охлаждения. | `processors`, `motherboards`, `ram_modules`, `video_cards`, `storage_drives`, `power_units`, `pc_case`, `processor_cooling` |
| **Сохранение сборок**          | Пользователь может сохранить конфигурацию, указать название, задать публичность. | `pc_configurations` (`id_user`, `build_price`, `is_public`, `created_at`) |
| **Множественная ОЗУ**          | Поддержка установки 1–4+ модулей RAM с указанием количества. | `pc_config_ram` (`id_pc_config`, `id_ram_module`, `quantity`) |
| **Множественные накопители**   | Возможность добавить несколько HDD/SSD/NVMe, пометить загрузочный диск. | `pc_config_storage` (`id_pc_config`, `id_storage`, `is_boot`) |
| **Автоматическая оценка сборки** | Проверка совместимости, расчёт TDP, поиск узких мест, оценка производительности (0–100). | `pc_build_assessment` (`performance_score`, `power_draw_watts`, `compatibility_issues JSONB`, `bottleneck_analysis JSONB`, `is_compatible`) |
| **Рецензирование**             | Пользователи оставляют рейтинг (1–5) и комментарий к публичным сборкам. | `reviews` (`id_pc_config`, `id_user`, `rating`, `comment`, `created_at`) |
| **Аналитика активности**       | Полный лог действий: просмотр компонентов, сохранение/редактирование сборок, поиск, вход. | `user_activity_log` (`id_user`, `action_type`, `target_id`, `target_type`, `timestamp`) |
